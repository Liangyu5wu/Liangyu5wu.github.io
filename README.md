# Liangyu Wu - Academic Website

This repository contains the source code for Liangyu Wu's personal academic website, built with Hugo Blox Builder.

## About

A personal academic website showcasing research interests, publications, projects, and professional experience in experimental particle physics and astro-particle physics.

## Built With

- [Hugo](https://gohugo.io/) - Static site generator
- [Hugo Blox Builder](https://hugoblox.com/) - Academic theme
- Deployed on [Netlify](https://netlify.com/)
